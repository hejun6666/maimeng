# 领星 SKU 补货下单助手使用说明

## 日常批量用法

先让 Codex 使用 browser-use 打开或接管用户自己的 Chrome 领星 ERP 网页，进入 `销售 > Listing`，筛选要分析的范围，例如国家、店铺、在线状态、负责人、品牌或更多筛选。

然后在 Codex 输入：

```text
[$lingxing-replenishment-planner]
请使用 browser-use 打开或接管用户自己的 Chrome 领星网页，进入销售 > Listing 并筛好范围。
批量分析销售 > Listing 当前筛选结果里的所有 SKU，生成补货建议表。
```

Codex 会通过 browser-use 读取用户 Chrome 里当前领星网页筛选结果的 SKU 销量，再去 `仓库 > FBA库存明细` 匹配 FBA 和 AWD 库存，最后输出批量补货建议表。

## 临时单 SKU 用法

```text
[$lingxing-replenishment-planner]
分析 SKU：FL-DE12GB-A
```

单 SKU 只适合临时查某个品。日常补货建议优先使用 Listing 批量模式。

## 不需要填写

- 不需要逐个输入或复制所有 SKU。
- 不需要填写当前月份，Codex 按系统日期自动识别。
- 不需要填写补货频率、入仓延迟、安全库存线、库存上限、目标库存天数、MOQ、箱规、采购单、断货、清仓、新品、促销或广告变化。

## 后台默认口径

这些是 skill 背后用于粗算和判断的默认口径，不是让同事填写的字段。

| 默认项 | 当前口径 | 说明 |
| --- | --- | --- |
| 当前月份 | 系统日期自动识别 | 用户主动说算未来某个月时，才按用户说的月份。 |
| SKU范围 | Listing 当前筛选结果 | 销售 > Listing 决定本次批量分析哪些 SKU。 |
| 销量口径 | 优先近30天销量 | 7天/14天销量主要用于趋势参考；30天缺失时才兜底。 |
| 海外库存 | FBA总库存 + AWD可用+在途库存合计 | 用于计算库存可撑天数。 |
| 即时可售 | FBA可售单独提示 | 用于判断短期可卖压力，不替代海外库存口径。 |
| 补货参考节奏 | 默认每周参考量 | 批量表先给每周补多少；销量明显不稳时再提示人工看。 |
| 生产周期 | 15天 | 用户主动提供不同周期时，用用户说的。 |
| 货代等待 | 3天 | 用户主动提供不同等待天数时，用用户说的。 |
| 运输天数 | 普船海运37天 | 用户主动说快船、空运或其他天数时，用用户说的。 |
| 默认提前期 | 15 + 3 + 37 = 55天 | 第一版不额外让同事填入仓延迟。 |
| 库存偏低粗判 | 低于约30天 | 只做风险提示，不让同事填写安全库存线。 |
| 库存偏高粗判 | 高于约90天 | 只做风险提示，不让同事填写库存上限。 |
| 目标粗算 | 约90天库存 | 用于估算工厂下单建议，不作为同事输入项。 |
| 采购单/待到货 | 第一版不主动计入 | 只有用户明确要求考虑已有采购或待到货时才处理。 |
| 旺季/主推 | 用户主动说明才加权 | 没有明确旺季、主推或倍率时，不强行放大销量。 |

## 输出字段

- SKU
- 品名
- 站点/店铺
- 近30天销量
- 日均销量
- FBA总库存
- FBA可售
- AWD库存
- 海外库存合计
- 库存可撑天数
- 风险等级
- 每周补货参考量
- 工厂下单建议量
- 需要人工确认的问题

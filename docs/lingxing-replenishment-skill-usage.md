# 领星 SKU 补货下单助手使用说明

## 日常批量用法

先在领星 ERP 打开 `销售 > Listing`，筛选要分析的范围，例如国家、店铺、在线状态、负责人、品牌或更多筛选。

然后在 Codex 输入：

```text
[$lingxing-replenishment-planner]
批量分析销售 > Listing 当前筛选结果里的所有 SKU，生成补货建议表。
```

Codex 会读取当前筛选结果里的 SKU 销量，再去 `仓库 > FBA库存明细` 匹配 FBA 和 AWD 库存，最后输出批量补货建议表。

## 临时单 SKU 用法

```text
[$lingxing-replenishment-planner]
分析 SKU：FL-DE12GB-A
```

单 SKU 只适合临时查某个品。日常补货建议优先使用 Listing 批量模式。

## 不需要填写

- 不需要逐个输入或复制所有 SKU。
- 不需要填写当前月份，Codex 按系统日期自动识别。
- 不需要填写补货频率、入仓延迟、安全库存线、库存上限、目标库存天数、MOQ、箱规、采购单、断货、清仓、新品、促销或广告变化。

## 输出字段

- SKU
- 品名
- 站点/店铺
- 近30天销量
- 日均销量
- FBA总库存
- FBA可售
- AWD库存
- 海外库存合计
- 库存可撑天数
- 风险等级
- 每周补货参考量
- 工厂下单建议量
- 需要人工确认的问题

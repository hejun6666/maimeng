# 1688 源头厂家筛选询价助手使用说明

这个 Skill 给采购同事使用，目标是在 1688 网页端找更像源头厂家的供应商，像真人采购一样逐家询价，并导出公司采购跟进表。

## 适合什么情况

- 有产品图片，想在 1688 找同款或相似款厂家。
- 有产品关键词，想找一批供应商对比。
- 有 1688 商品链接，想继续找同款、相似款或更像工厂的店铺。
- 已经打开 1688 搜索页，希望 Codex 帮忙筛选和询价。

## 使用前准备

1. 打开 Codex。
2. 确认已经安装 `1688-source-factory-finder` Skill，并重启过 Codex。
3. 准备产品图片、关键词、1688 商品链接，或者先打开 1688 网页端。如果有产品对标链接，也可以一起给 Codex。
4. 1688 账号密码只在 1688 网页里登录，不要发到 Codex 聊天里。

建议使用 Chrome 或 Edge 的网页端 1688。这个 Skill 使用的是开源项目 Browser Use 的 `browser-use` 命令来控制用户自己的可见浏览器，不是 Codex 内置 Browser 插件。暂不按手机端或 1688 客户端设计。

## 推荐开场

```text
请帮我找这个产品的1688源头厂家并逐家询价。我会提供图片、关键词、1688链接或当前页面；默认问7-9家，直接按默认话术一家一家发，最后给我总结并导出Excel。
```

也可以说：

```text
我有一张产品图，帮我找1688源头厂家，问7-9家左右。
```

```text
帮我找婴儿围栏的1688厂家，直接按默认话术问，不用先问我确认话术。
```

## Codex 会怎么做

1. 先问你手上有什么：图片、关键词、链接，还是当前页面。
2. 引导你打开或登录 1688 网页端。
3. 用图片搜索、关键词搜索或当前页面找候选店铺。
4. 先筛掉明显不合适的供应商。
5. 默认选择 7-9 家供应商，不会先停下来让你确认话术。
6. Codex 会先把当前商品卡片/商品链接发给客服，再发默认询价话术。
7. 发完一轮后进入回复收集轮，统一回到消息页看真实客服回复。
8. 还没回复的供应商会先标记为 `待回复`；如果过了有限回查轮次仍不回复，会标记为 `超时未回复/暂不跟进`，不会一直拖住整个产品。
9. 只有真的发过询价消息，才算进入正式采购跟进表；只筛选出来的店铺只能叫候选清单。
10. 最后先在聊天里总结，再导出 Excel 对比表。
11. 如果还在等回复，Codex 可以用当前线程的 heartbeat 稍后回来继续回查；单个产品不会默认创建每天运行的 cron。任务结束后，如果不需要继续看 1688 页面，Codex 会用 `browser-use close --all` 关闭 browser-use 会话，避免浏览器窗口关了又弹。

## 默认询价话术

```text
你好，这款有现货吗？我想了解一下起订量、含税阶梯价和交期。另外想确认下你们是工厂直供还是经销？如果打样的话，打样费、打样货期，以及后续下大货是否可退样品费，也麻烦一起说下。
```

Codex 会根据产品名或页面规格稍微改写，不会机械复制给每一家。

## 遇到这些情况会停下来

- 1688 要登录、验证码、滑块、风控提醒。
- 客服问具体数量、规格、颜色、型号、包装或定制，而且页面和上下文无法判断。
- 客服要求手机号、微信、公司信息；Codex 会优先礼貌要求对方直接在 1688 里发，只有涉及真实业务信息或账号风险才停下来问你。
- 页面涉及付款、下单、合同、提交订单。
- Codex 看不懂页面，无法判断下一步是不是发送消息。

这时你按 Codex 提示处理即可。Codex 不会自己编采购数量、地址、公司信息或付款承诺。

## 输出结果

Codex 会先在聊天里给结论：

- 已筛选多少家。
- 已询价多少家。
- 最值得跟进的 3 家。
- 暂不建议的供应商和原因。
- 哪些还没回复。

然后导出 Excel，前面的字段会按公司采购表来：

```text
产品图片、产品品名、产品对标链接、供应商、报价含税价、起订量、交期、链接、备注、样品负责人、进度
```

Excel 只保留这些公司采购表字段，不额外增加 AI 辅助列。是否像工厂、样品费、是否退样品费、后续动作等信息放在 `备注` 或聊天总结里。

如果 Codex 还没有问客服，或者只是停留在搜索结果页，这个文件不能当作最终采购表。`链接` 字段也不能填搜索结果链接，必须是具体商品页、店铺页或能回到该供应商的直接链接。

报价、MOQ、交期、打样费等字段应优先来自客服新回复。页面已有价格只能标注为页面展示信息，不能冒充客服回复；未税价可以保留在报价列，但必须标明“未税报价（非含税价，开票/税点见原话）”。没有回复就写 `未回复` 或 `待回复`。

后续客服回复后，可以再对 Codex 说：

```text
帮我整理昨天1688客服回复，看看哪几家值得继续问。
```
